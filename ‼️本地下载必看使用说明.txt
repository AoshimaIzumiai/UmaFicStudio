==================================================
  UmaStudio 本地使用说明
==================================================

解压后你会得到一个 UmaStudio 文件夹，
里面有网站的所有文件。

请根据你的电脑系统，按下面的步骤操作：


【Mac 用户】
--------------------------------------------------

1. 打开"终端"
   方法：按 Command+空格，输入"终端"，回车

2. 在终端里输入以下内容（直接复制粘贴）：
   cd ~/Downloads/UmaStudio
   
   （如果你把文件夹放在别的地方，把路径改成对应位置）

3. 继续输入：
   python3 -m http.server 8080

4. 看到类似 "Serving HTTP on..." 的字样就成功了

5. 打开浏览器（Safari、Chrome 都行），
   地址栏输入：http://localhost:8080
   回车，就能看到网站了！

6. 用完之后回到终端，按 Control+C 关闭服务


【Windows 用户】
--------------------------------------------------

1. 打开"命令提示符"
   方法：按 Win+R，输入 cmd，回车

2. 输入以下内容（把路径改成你实际解压的位置）：
   cd C:\Users\你的用户名\Downloads\UmaStudio

3. 继续输入：
   python -m http.server 8080

   ⚠️ 如果提示"python 不是内部命令"，说明你没装 Python，
   请看下面的【安装 Python】部分。

4. 看到 "Serving HTTP on..." 就成功了

5. 打开浏览器（Chrome、Edge 都行），
   地址栏输入：http://localhost:8080
   回车即可使用！

6. 用完后回到命令提示符窗口，按 Ctrl+C 关闭服务


【安装 Python（仅 Windows 用户可能需要）】
--------------------------------------------------

Mac 自带 Python，不用装。
Windows 如果没有 Python，按以下步骤安装：

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击黄色大按钮 "Download Python 3.x.x"
3. 运行下载的安装程序
4. ⚠️ 重要！安装界面底部勾选 "Add Python to PATH" !!
5. 点 Install Now，等待安装完成
6. 重新打开命令提示符，再试一次上面的步骤


【常见问题】
--------------------------------------------------

Q: 打开网页是空白的？
A: 确认你在终端/命令提示符里看到了 "Serving HTTP" 字样，
   并且浏览器地址是 http://localhost:8080（不是 https）

Q: 我的数据保存在哪里？
A: 保存在浏览器里（不是文件夹里）。
   只要用同一个浏览器打开就还在。
   可以用"导出数据"按钮备份成文件，可以随时再导入。

Q: 换电脑怎么办？
A: 先在旧电脑上"导出数据"保存 JSON 文件，
   在新电脑上打开网站后"导入数据"即可。

Q: 关掉终端/命令提示符后网站打不开了？
A: 正常的！每次要用的时候都需要重新运行那个命令。
   你的数据不会丢失，放心。
